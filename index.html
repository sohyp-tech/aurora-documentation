Introduction

A modern, ultra-lightweight, utility-first CSS framework. Build beautiful interfaces without fixed colors.

Add the stylesheet to your HTML head:

<link rel="stylesheet" href="https://sohyp-tech.github.io/aurora/aurora.css">

Layout & Flexbox

Utilities to control the structure and alignment of elements.

ClassDescription
a-flexSets display to flex.
a-centerCenters content horizontally & vertically.
a-items-centerAligns items vertically.
a-content-centerAligns content horizontally.
a-content-startAligns content to start.
a-content-endAligns content to end.
a-content-betweenPushes items to the edges.
a-content-aroundDistributes items with space around.
a-flex-colSets flex direction to column.
a-flex-rowSets flex direction to row.
a-flex-wrapAllows items to wrap.
a-gap-{2|4|6|8|10}Sets the gap between items.

Spacing (Padding & Margin)

Spacing follows a simple pixel-based scale: 0, 2, 4, 6, 8, 10.

Class PatternExampleDescription
a-p-{size}a-p-4Padding on all sides.
a-p-top-{size}a-p-top-8Padding on the top.
a-p-bottom-{size}a-p-bottom-8Padding on the bottom.
a-p-left-{size}a-p-left-8Padding on the left.
a-p-right-{size}a-p-right-8Padding on the right.
a-mg-{size}a-mg-2Margin on all sides.
a-mg-top-{size}a-mg-top-8Margin on the top.
a-mg-bottom-{size}a-mg-bottom-8Margin on the bottom.
a-mg-left-{size}a-mg-left-8Margin on the left.
a-mg-right-{size}a-mg-right-8Margin on the right.

Typography

Control text colors, weights, and fonts.

ClassDescription
a-text-colorSets text color using var(--text-color).
a-text-familySets font family using var(--font-family).
a-text-weight-{100-900}Sets font weight (e.g., 100, 400, 700).
a-text-weight-boldSets font weight to bold.
a-text-weight-bolderSets font weight to bolder.
a-text-weight-inheritInherits font weight from parent.
a-text-weight-initialSets font weight to initial.
a-text-shadowApplies text shadow using var(--ts).

Borders & Radius

Utilities for borders and rounded corners.

ClassDescription
border-solid{1-5}Applies a solid border (e.g., border-solid1).
border-dashed{1-5}Applies a dashed border.
radius-{2-20}Applies border-radius (e.g., radius-8).

Width & Height

Control the dimensions of elements.

ClassDescription
a-wSets width to var(--width).
a-w-fullSets width to 100%.
a-w-halfSets width to 50%.
a-hSets height to var(--height).
a-h-fullSets height to 100%.
a-h-halfSets height to 50%.

Effects & Filters

Shadows, opacities, and backdrop filters.

ClassDescription
a-box-shadowApplies a box shadow using var(--bs).
a-opacity-100Sets opacity to 1.
a-opacity-75Sets opacity to 0.75.
a-opacity-50Sets opacity to 0.50.
a-opacity-25Sets opacity to 0.25.
a-bd-filterApplies backdrop blur using var(--blur-num).
